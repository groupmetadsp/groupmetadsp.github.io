Страница объединяет основные принципы проектирования, типовые схемы размещения и проверочный чек-лист.

Типовые схемы

8 исходных схем. Можно просмотреть все варианты или подобрать решение по расположению стены.

Тип стены
Выбери расположение стены — ниже появятся только подходящие исходные схемы.
Фильтр отбирает только схемы, присутствующие в каталоге. Чертежи, размеры и подписи не изменяются.

Правила формирования

Чертежи сохраняются без перерисовки.
Сетка строится вокруг реальных вариантов.
Режим подбора показывает те же исходные схемы.
Никаких придуманных размеров, сантехники, человечков и решений.
Новые варианты добавляются только из предоставленных вами схем.
