Расчёт

Лоджии уже входят в Sпрод. Их площадь вычитается из расчётной Sобщ для плотности; цель Sпрод сохраняется.

Используем максимальную общую надземную площадь по плотности. 3D показывает только текущую фактическую компоновку.

Формулы и база площадей

К перехода = Sобщ / Sстр. Стартовое значение 0,96 — предварительная оценка при толщине стены 250 мм без утеплителя и навесного фасада. Требуется калибровка по обмеру секций и сверка правил учёта шахт. При К перехода = 1 возвращается прежняя методика.

Предел по плотности = площадь участка × плотность. При ручном ограничении используется меньшее из двух значений.

Продаваемая площадь без лоджий = квартиры без балконов и лоджий + надземная коммерция + коммерция на перепаде рельефа. В сценарии продажи с лоджиями добавляется 100% их площади. Sстр без лоджий = (квартиры без балконов и лоджий + надземная коммерция) ÷ КЭП. Sобщ без лоджий = Sстр × К перехода. Sобщ с лоджиями = Sобщ без лоджий + введённая площадь балконов и лоджий.

Цель по надземной продаже = максимум из 0 и (общая цель по ТЭП − коммерция на перепаде рельефа). Цель по квартирам дополнительно уменьшается на надземную коммерцию.

Потенциал без лоджий = (предел надземной площади − учитываемая в плотности площадь лоджий) ÷ К перехода × КЭП + коммерция на перепаде рельефа. Потенциал с лоджиями дополнительно включает их текущую площадь. КЭП задан на базе продажи без лоджий.

КЭП в модели — единый коэффициент для квартир и коммерции, рассчитанный на строительную площадь без балконов и лоджий в принятой базе модели. Минимальный КЭП = (квартиры без лоджий + надземная коммерция) × К перехода ÷ (предел Sобщ − учитываемая в плотности площадь лоджий).
